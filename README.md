# 별이 내리는 밤, 너와

> 비 오는 금요일, 작은 카페에서 시작된 다섯 번의 밤.  
> 별을 그리는 그녀와, 별을 잃어버린 당신의 이야기.

한국어 로맨스 비주얼 노블. 선택지에 따라 **호감도**와 **신뢰**가 달라지고,
마지막 금요일의 선택에 따라 네 가지 엔딩으로 이어집니다.

- 5개 챕터 · 192개 장면 · 4개 엔딩
- 자동 저장 / 수동 저장 / 이어하기
- 대화 기록 · 추억 보관함 · 설정(글자 속도, 화면 흔들림, 소리)
- 데스크톱과 모바일을 모두 지원하는 반응형 UI
- 외부 이미지 없이 SVG로 그린 배경과 인물, Web Audio로 만든 음악

## 플레이 방법

저장소 루트의 `index.html`을 정적 서버로 열면 바로 플레이할 수 있습니다.

```bash
python3 -m http.server 3002
```

브라우저에서 `http://localhost:3002`를 엽니다.

| 조작 | 기능 |
| --- | --- |
| 클릭 / Space / Enter | 대화 진행 |
| 숫자 1–4 | 선택지 선택 |
| Esc | 메뉴 열기·닫기 |
| A | 자동 진행 |
| G | 추억 보관함 |
| S | 소리 켜기·끄기 |
